 ## Credit Dashboard
 
This project analyzes the full credit‑flow process of a retail credit company in Ecuador using data from January to November 2025. The goal is to understand how prospects move through the credit funnel, identify bottlenecks, and highlight opportunities to improve conversion, risk management, and geographic strategy.
The dashboard provides interactive visualizations built with Streamlit, allowing users to explore:

- Funnel performance (Applicants → Pre‑Approved → Credit Started → Sales)
- Income and financial expense distributions
- Geographic sales patterns using a choropleth map
- Risk score distributions across stages
- Supervisor approval performance
- Monthly credit activity trends
- Formality and employment‑type behavior
  
The analysis reveals strong demand but significant drop‑offs in the funnel, with the best conversion among younger, formally employed applicants. 
Coastal provinces show the highest sales potential, and most approved clients fall within low‑risk score ranges(800-1000).
